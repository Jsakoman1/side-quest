# SideQuest

SideQuest is a local task marketplace that helps people find support for everyday tasks and gives others the opportunity to earn extra money through side jobs.

Whether someone needs a dog walker, pet sitter, help with watering plants during vacation, lawn mowing, or another small task, they can create a quest. Users looking for side jobs can browse available quests and apply for them.

## Tech Stack

- Backend: Java, Spring Boot
- Database: PostgreSQL
- Frontend: Vue.js, TypeScript

## Features

- Quest creation
- Quest listing
- User selection
- Quest applications
- Application overview per quest

## Purpose

The application is designed to connect task owners with people who are available to help locally, such as students or anyone looking for flexible side income.
